# 成片字体

`NotoSansCJK-Bold.ttc` 是 Noto Sans CJK Bold 开源字体，原样复制自 K3 已安装的 Debian/Bianbu `fonts-noto-cjk` 包。字体版权与 SIL Open Font License 1.1 全文见 `OFL.txt`。

上游：https://github.com/notofonts/noto-cjk

两端成片优先加载这份字体，避免 Windows 微软雅黑和 Linux Noto 导致字宽、字形不同。不要用系统专有字体替换随项目分发的文件。不同系统的 FreeType 抗锯齿实现可能在少量英文边缘像素上有差异，字体与字号相同不代表图片逐像素相同。
