# 展前检查单（2026-10-09 定稿）

每天开展前 10 分钟，按顺序过一遍。全部通过 ≈ 3 分钟。

## 1. 服务与组件（一台手机或笔记本浏览器即可）

打开 `http://192.0.2.10:8090/api/health`，应看到：

```json
{"ok": true, "components": {"gesture": {"status": "ok", ...}}}
```

- `gesture` 不是 `ok` → `systemctl restart devcon-booth`，再查；
- 仍不行 → `journalctl -u devcon-booth -n 30` 找「手势」行。

## 2. 相机

打开 `http://192.0.2.10:8090/stage`，取景框应有实时画面。
没画面 → `/operator` 面板点「USB 复位」，等 10 秒。

## 3. 二维码

拍摄位首页（`http://192.0.2.10:8090/`）右侧「扫码排队」应有二维码。
**当前指向**：`http://192.0.2.10:8090/join`（局域网）——要求手机与装置同 WiFi。
**东京 nginx 恢复后**要切回公网域名：`/operator` 面板 → 地址改为 `https://pick.example.com` → 保存（二维码自动换新）。
判断公网是否恢复：手机流量（不连 WiFi）打开 `https://pick.example.com/join`，能打开就是恢复了。

## 4. 打印机

打印机亮着、同一网段即可。板上验证：

```bash
lpstat -p   # 应显示 HP_LaserJet_MFP_M233sdw_435600 空闲
```

缺纸/卡纸先处理，CUPS 队列会自动重试。

## 5. 全流程真人演练（开展前必做一次）

1. 手机连现场 WiFi → 扫码 → 选风格 → 提交
2. 到号 → 点「开始拍摄」→ 页面提示「比出 OK 手势」
3. **站到镜头前 1~2 米、正对镜头，比 OK（拇指食指圈圆）保持约 15 秒**
4. 自动倒计时 3 秒 → 拍摄 → 等 AIGC（30~96 秒）
5. 手机自动到取图页 → 点「保存原图」「打印照片」
6. 打印机出 4x6 一张 → 收工

第 3 步若 30 秒无反应：操作员面板看日志，若一直「未识别到 OK 手势」→
`/etc/systemd/system/devcon-booth.service.d/gesture.conf` 把 `BOOTH_GESTURE_PINCH_MAX`
从 0.25 放宽到 0.30，`systemctl daemon-reload && systemctl restart devcon-booth`，再试。
若出现无人也开拍 → 把 `BOOTH_GESTURE_PERSON_PAD` 从 0.15 收紧到 0.10，同上重启。

## 快速排障索引

| 症状 | 第一动作 |
|---|---|
| 全页打不开 | `systemctl status devcon-booth`；崩了会自动重启（StartLimitIntervalSec=0） |
| 相机黑屏 | `/operator` → USB 复位 |
| 手势没反应 | 见第 5 步调参；确认人足够近（det 检不出人形时手势永远判阴性） |
| 打印没反应 | `lpstat -o` 看队列；`/operator` 看打印组件状态 |
| 手机打不开二维码地址 | 确认同 WiFi；或按第 3 步切地址 |
