## 3. 采集方案取舍（关键决策）

| 方案 | 画质 | 现场复杂度 | 成本 | 建议 |
|---|---|---|---|---|
| **A. 笔记本/平板浏览器取像**（getUserMedia） | 中（受设备摄像头限制） | 低，零驱动 | 0（用现有设备） | **默认**。需要 Chrome 白名单参数（见部署文档） |
| **B. K3 + USB UVC 摄像头**（服务端取像） | 中 | 中，单机 | 400–1500 | 单机部署更干净，但 K3 无板载采集设备，必须外接 USB |
| **C. 无反相机 + HDMI 采集卡** | 高 | 中高，驱动/采集卡 | 3000–8000 | 画质要求高时选。彩排必须验证采集卡在目标系统上免驱可用 |
| **D. 相机拍 → 读卡器导入** | 最高 | 高，多一步人工 | 0（用现有相机） | 只作**保底通道**，不用于主流程（会打断 35 秒节拍） |

**推荐组合：A 为主 + D 为保底。** 理由：A 的零驱动特性在现场最不容易出事，
而画质对「强风格化」输出影响有限——风格化本身会重绘画面。

| P4 | **热升华照片打印机**（替换拍立得） | 如呈妍 P525L / 西铁城 CX-02 | 1 | 2000–6000 | **不要用拍立得**，理由见下 |
| P5 | 热升华耗材 | 每张纸色带套装 | 300–500 | 1.8–3.0 /张 | 只有限量冲印时才需要 |
| P6 | 二维码立牌 | 亚克力台卡 A5 | 2 | 30–70 /个 | 取图二维码放**取图位**，不放拍摄位（避免队伍堵在拍摄位） |

> **为什么不用拍立得（需求原文提到）**
> 拍立得相纸单张成本高、出片 90 秒以上、有卡纸与耗材断供风险，且会成为整条流水线的瓶颈。
> 在 500 人量级下不可行。替代方案：
> - **数字照片 = 人人可得的主交付**（扫码取图，零边际成本）；
> - **徽章贴纸 = 人人可得的实体**；
> - **热升华冲印 = 限量**（前 N 名 / 集齐印章 / 嘉宾），约 60 秒/张、约 2 元/张，成本与速度都优于拍立得；
> - 若坚持用拍立得，**必须限量**并安排专人值守换纸，且明确它不参与主流程计数。

## 8. 搭建流程（建议 1.5 天窗口）

```
前一晚 / 布展日 上午
  ├─ 场地实测（展位尺寸、插座位置与数量、承重墙/背板条件）
  ├─ 背景板安装（先立背板，再调灯光）
  └─ 道具墙固定（防倾倒，尤其人流密集时）

布展日 下午
  ├─ 灯位粗调 → 相机位固定 → 拍测试照确认构图
  ├─ 走线：线槽固定全部供电与网线，胶带压边
  ├─ 设备上电顺序：网络 → K3 → 大屏 → 取图终端
  └─ 系统自检：跑 app/tests/e2e_test.py，全绿再进入彩排

彩排（务必留足 2 小时）
  ├─ 真人实测三种风格，看边缘与光照表现
  ├─ 连续 n 人无人工干预跑通（n 见彩排清单）
  ├─ 拔网线测试离线可用
  ├─ 真手机扫二维码（开发机的解码器通过 ≠ 手机能扫）
  └─ 故障演练：拔电源、杀推理进程、点一键恢复
```

## 9. 打包与运输

- 背景板/展架/道具墙：按「可拆装 + 编号标记」打包，箱外贴内容清单。
- 电子设备：**一个运输箱 + 一张清单 + 一份备件**（备用电源、网线、U 盘、启动盘）。
- 建议做**一份整盘镜像备份**：现场 K3 挂了可直接换盘或换机，5 分钟内恢复。
- 搭建图纸与清单各打印一份放工具箱——现场没人愿意翻手机找图。
