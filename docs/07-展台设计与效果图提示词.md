## 1. 设计命题（一句话）

**这不是一个拍照摊，是一个「看得见算力」的展台。**

背景板、灯、相机、水印，任何公司都能做。我们唯一不可替代的东西是：
**这张照片是脚边那块 RISC-V 板子自己算出来的，而且参会者能看见它算的过程。**

于是展台设计只有一条主线：**让芯片在物理上可见**。
一张光秃秃的背景板 + 一台看不见的电脑，等于把这个装置的灵魂藏起来了。

配套的三条副线：
1. **排队时就有东西看**（大屏在队伍的视线里，不是背对队伍）；
2. **30 秒能看懂自己在哪一步**（拍摄位有自己的屏，不做"哑巴工位"）；
3. **拍完不堵在拍摄位**（取图位与拍摄位分开 ≥1.5m）。

## 3. 布局：3m × 3m

### 3.1 五个区

```
        ┌──────────────────── 背景板 3000×2400 ────────────────────┐
        │                                                          │
 道具墙 │                     ● 站立位地贴                          │  大屏
 1800   │                     ↑ 1100mm                             │  43"
 ×1200  │                     │                                      │  斜 20°
        │                     │ 视轴                                 │  朝队伍
        │                     ↓ 1500mm                             │
        │                   ▣ 机位三脚架                            │
        └──────────────────────────────────────────────────────────┘
              ▲                                            
         排队进入                                    ┌─── 取图位 ───┐
      （大屏在这一侧可见）                            │ 取图平板      │
                                                     │ 二维码台卡 ×2 │
                                                     │ 贴纸发放      │
                                                     └──────────────┘
```

| 分区 | 位置 | 停留时长 | 关键点 |
|---|---|---|---|
| ① 等候 / 观看 | 展位外侧 + 右前方 | 60–180s | 大屏必须在这个人的视线里，否则排队时间是浪费的 |
| ② 拍摄 | 展位中央，离背板 1100mm | 20–30s | 站定即拍。地贴定死位置，构图每张都一样 |
| ③ 算力展示 | 设备台，靠左或靠后 | 5–20s | K3 透明展示罩 + 大屏。**这是本装置的差异化，不要藏在桌下** |
| ④ 取图 | 右前方，离拍摄位 ≥1500mm | 10–20s | 扫码拿走。**不能和拍摄位挤在一起** |
| ⑤ 发贴纸 | 与取图位同台 | 3–5s | 「开发者见证者」，实体纪念 |

### 3.2 三条动线

- **主循环**：排队 →（看大屏）→ 站上地贴 → 勾同意/快门 → 大屏上看见自己的掩码成形 → 走到取图位 → 扫码取图 → 拿贴纸 → 离开。
- **不进队的人**：站在展位前沿 1m 外看大屏就够 —— **大屏要能"路过即懂"**。
- **不回头**：取图位出口方向不与人流交叉。

### 3.3 灯光位（三盏各司其职）

| 灯 | 位置 | 作用 |
|---|---|---|
| 主光 | 站位左前 45°，略高于眼 | 脸的主造型 |
| 侧光 / 补光 | 站位右前 45°，功率低一档 | 压掉主光的硬阴影，补下巴 |
| 背板轮廓光 | 背板顶端或侧后方，打向背景板 | 把人和背景板分开。**没有这一盏，人和暗色背景会糊成一片** |

> **不要用环形灯。** 环形灯是"直播间"的语言，和这套暗调工业质感是冲突的。
> 柔光箱 + 反光板能做出同样的皮肤质感，而且更像"工程现场"而不是"网红打卡"。

### 3.4 背景板尺寸有一条硬算法（★ 最容易出错）

主视觉是 **16:9**（1600×900），背景板是 **3000×2400**（5:4）—— **两个比例不一样**。

- ❌ **不要为了铺满 2400 高而左右裁** —— 会切掉左上角的品牌锁定组，那是整个视觉的锚。
- ✅ **按宽度铺满**：3000mm 宽 → 主视觉高 **1687.5mm**。上沿贴齐 2400mm，**下面留 712.5mm 的纯暗场落地**。

为什么下面留空反而是对的：站位离背板 1100mm，相机拍的是半身到全身，
**人的下半身对应的正是背板最下段**。这段放纯暗场，不会出现"半截图案卡在腰上"。

**还有一个印刷分辨率的坑**：主视觉文件是 1600×900 —— 直接拉成 3000mm 宽只有
**13.5 dpi**，站在 1.1m 外看会明显发虚。送印前必须重出 **≥6000px 宽（≈50 dpi）** 的大图。

### 4.4 出图参数与三张分镜

| 图 | 提示词改法 | 比例 | 用途 |
|---|---|---|---|
| ① 参观者视角 | 母版 + `camera at eye level, 2 m in front of the booth, as if walking up, slight wide angle` | 16:9 | 评审主图、给品牌方看 |
| ② 侧 45° 全景 | 直接就是母版 | 16:9 | 给搭建商看结构 |
| ③ 俯视轴测 | 母版 + 把视角句换成 `isometric top-down 3/4 view of the whole booth, floor plan readable, no perspective distortion` | 4:3 | 给采购看"东西摆在哪" |

**分辨率**：1536×864 或 2048×1152。暗调图分辨率太低会起色带，**别出 1024 宽以下的**。

### 4.5 两个一定会翻车的点

1. **画面里的文字，模型一定会写错。** 上面提示词里点名了品牌锁定组，是为了让画面
   **结构**对（左上角有一块标识、下面是暗场），**不是指望它把字写对**。
   最终效果图里的 Logo，要用**真实的主视觉文件再贴一次**（或直接把我们的主视觉当
   参考图喂进去）。评审时被人指着一个拼错的 Logo，比没有 Logo 更尴尬。
