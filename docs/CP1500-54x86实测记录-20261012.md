# CP1500 USB · 54×86mm 卡片接入实测

日期：2026-10-12。用户已连接打印机并明确使用 54×86mm 耗材，授权打印实测与流程接入。

## 实际设备与链路

- K3：192.0.2.10，现场服务 /opt/devcon/app，8090 端口。
- USB：04a9:3302，Canon SELPHY CP1500，连接点 usb 7-1.3。
- CUPS：2.4.16-1ubuntu1；ipp-usb：0.9.31-1，已有软件，无需下载安装。
- 打印机属性：Canon SELPHY CP1500 HTTP，media-ready=om_card_54x86mm。
- 原自动发现队列为 implicitclass://Canon_SELPHY_CP1500_USB/，默认 Postcard；该默认与实际耗材不符。
- 新增专用队列 DevCon_CP1500，直接指向 ipp://127.0.0.1:60000/ipp/print，驱动 everywhere，不共享队列。
- 队列默认 54x86mm.Borderless，print-scaling=fill，故障策略 stop-printer。发生不确定提交/失败时不自动重新出片。
- 现场原 print.conf 指向 HP LaserJet，本次已改为 CP1500 专用配置。其他打印机及原自动发现队列保留。

## 两张真实打印

来源：已有授权测试成片 SM-2026-0034，1024×1536。

前两张打印画布为 638×1016、300dpi；完整电子照片等比居中，约 3mm 内安全边距，因此实物出现了明显白边。12:02 起版面改为居中等比裁切铺满，不再创建白色画布，CUPS 同时由 fit 改为 fill。该改法会轻微裁掉长边两侧内容，但不会拉伸人像。

第二张 POST /api/print 连续请求两次返回相同应用作业 b120d4af743f；只新增一个 CUPS 作业。GET /api/print/<id> 返回 submitted 后变 completed，没有将“提交成功”冒充“打印完成”。

服务重启后同幂等键再次提交，仍返回 b120d4af743f / completed。浏览器实际点击同一照片打印按钮后显示“打印完成，请取走卡片”且按钮禁用；CUPS 队列仍仅包含 11 和 12 两个测试作业，没有第三张。

第 14 张作业前，旧版纸面文件四边 3308/3308 个边缘像素接近纯白；新版 K3 生成文件为 0/3308。说明应用主动留白已经完全消除。设备报告作业完成，但纸面是否仍有机械边缘需要人工查看刚输出的卡片确认。

打印后相机实时检查：1920×1080 MJPG，预览 12 fps、last_frame_s=0.1、USB resets=0、fail_streak=0。此为本轮打印期间/之后的检查，不能外推为整天连续稳定。

## 已接入流程

拍摄 → AIGC → 扫码取图 → 保存电子版 → 点击“打印 54×86 卡片” → 排队/打印状态 → 完成后领取。

- 每张照片固定幂等键 pick:<随机令牌>，任务台账保存于 data/print-jobs.json，服务重启后仍不重复提交。
- 查询失败/超时仅提示状态确认中；不鼓励重打。
- 页面每 2 秒查询，最长 5 分钟；查询超时可继续查询相同作业。
- 开启前与提交前通过 IPP 查询设备和 media-ready，断线、停机、纸型不匹配或耗材异常时拒绝新打印。
- 纸面文件保存于 data/prints/<编号>.jpg；接入已有单张删除、清场和到期清理路径，不额外保留照片副本。
- 已准备 `app/deploy/cp1500-usb-postcard.conf`：若 54×86mm 实物仍有不可接受的硬件白边，换入 100×148mm 相纸/色带后可切回 Postcard.Borderless；应用会输出 1181×1748、300dpi 满版画布，并检查打印机实际装入的是 100×148mm 相纸。
- 默认 Windows 未启用 CUPS 时禁用打印按钮，电子取图仍正常。接入同一 CUPS 服务需单独配置，不伪报 Windows 本机能直接打印。
- 同步 K3 的服装锁定代码已部署；本次没有调用 AIGC 网关生成新图，不能据此声称服装保真已实测。

## 固定配置与复现

仓库配置 app/deploy/cp1500-usb.conf，对应 K3 /etc/systemd/system/devcon-booth.service.d/print.conf。

```sh
lpstat -v DevCon_CP1500
lpoptions -p DevCon_CP1500 -l
ipptool -tv ipp://127.0.0.1:60000/ipp/print /usr/share/cups/ipptool/get-printer-attributes.test
ipptool -tv ipp://localhost:631/jobs/12 /usr/share/cups/ipptool/get-job-attributes.test
```

直接测试图与 API 请求记录保存在 K3 /opt/devcon/print-tests/20261012/。此目录是验收证据，非参与者照片存储入口；本轮不删除历史文件。
