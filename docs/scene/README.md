# 装置5 现场图

七张图分三类，**用途和可信度完全不同，不要混用**。

## 一、工程图（尺寸准确，可直接用于搭建与报批）

| 文件 | 内容 | 用途 |
|---|---|---|
| `01-平面布置图.png` | 3m×3m 俯视：背景板、道具墙、站立位、机位、三盏灯、大屏、走线、取图位、人流动线、关键尺寸 | 搭建、报批、核对物料 |
| `02-立面图.png` | 正视图：背景板 3000×2400、大屏（**嵌入真实界面截图**）、灯架、机位、道具墙、离地尺寸 | 搭建、与主办核对高度限制 |
| `03-大屏内容.png` | 大屏上真正显示的画面（**真实截图，未修图**） | 评审大屏呈现、对齐口径 |
| `06-界面看板.png` | 四个界面的真实截图拼板：大屏 / 拍摄位 / 取图页 / 操作员面板 | 评审时一屏对齐各角色看到什么 |

这四张由程序化绘图脚本产出（生成脚本属于内部工具，未随仓库发布），**尺寸是实际安装尺寸**：

- 站立位离背板 1100mm，机位距站立位 1500mm（3m 进深下的可用构图区间）；
- 屏心离地 1170mm（站立舒适 + 排队越过前人肩可读）；
- 43" 屏可视区 950×540mm；
- 三灯：主光（左前）+ 侧光（右前）+ 背板轮廓光。

> 重绘时请沿用上面的实际安装尺寸；生成脚本未随仓库发布。

## 二、效果图（氛围示意，尺寸不可依赖）

| 文件 | 内容 |
|---|---|
| `04-效果图-参观者视角.png` | 参观者走近展位时的观感 |
| `05-效果图-侧视全景.png` | 侧四分之三视角：灯架、三脚架、单板机、平板、贴纸、排队人群 |

**这两张是图像模型生成的效果示意，不是现场照片，也不能当作施工依据。**
它们的作用只有一个：让人在采购和搭建之前，对观感有一个共同的心理图像。
图里的屏幕内容是模型想象的，**不是我们的界面**——真实界面以 `03-大屏内容.png` 为准。

## 三、关于「真实截图」

`02-立面图.png` 与 `03-大屏内容.png` 里的屏幕画面，是跑在**本机服务上的
`/stage` 页面被无头 Chrome 截下来的真图**，没有修图、没有重绘。

截图时用的是 **mock 后端（彩排模式）**，所以屏上的 EP 徽章显示 `MOCK`。
这不是缺陷，是刻意的诚实设计：非真实推理必须在界面上显形，
不允许 MOCK 冒充真机。现场切到 worker 后端后，同一位置会显示
`EP SpaceMIT` 与真实毫秒数。
