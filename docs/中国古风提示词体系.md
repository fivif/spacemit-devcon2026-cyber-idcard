# 中国古风

风格 ID：`chinese-elegance`。新增第七款风格，默认非 Q 版，也支持 Q 版大头像。

运行时正向、反向提示词以 `app/aigc_catalog.py` 的风格种子、服装规则和人像模式规则为准，后台风格页可编辑、启停、复制、恢复历史和删除。2026-10-13 预设升级至v9：只刷新本风格说明与正负提示词，原版保存为历史；名称、默认、模型、尺寸、启停和其他风格保留，已删除的风格不自动恢复。

## 固定视觉要求

- 单人正面头肩证件照，头部端正，直视镜头，双眼可见，面部清晰，光影柔和自然。
- 保持本人的脸型、五官比例、年龄、发型、眼镜；轻度美颜，不瘦脸、不替换成通用美化脸。
- 本风格允许换新中式服装，不再固定同一件立领上衣。立领、交领、斜襟、汉元素轻外搭任选一种；丝绸、亚麻、细织纹理与柔软褶皱提供轻盈层次，盘扣、同色刺绣或提花边择一，不堆满装饰。西装风继续换西装，普通其他风格仍保留原衣服。
- 视觉以现代国风插画为主，使用细腻线条、清透矿物色、水墨点染和柔亮光感，不再默认沉闷制服式棚拍。青绿、朱砂、竹青、玄黑和暖白是灵感，不是统一模板；允许协调的冷暖变化与小面积亮色。
- 每次自由选择一个完整画意，青绿竹影、朱砂桃色、青绿山水、暖白水墨只是举例，不要求一起出现。背景留白、低细节、不遮脸；变化来自衣料、配色、光色与笔触，不来自歪头、夸张表情或换脸。
- 科技感可选，只在缝线或颜料细节中自然融入一点几何元素，不强制每张出现。不使用霓虹、全息界面和复杂赛博场景。
- Q 版放大整体头部、缩小肩部，保留个人特征，不生成全身小人；非 Q 版保持自然头肩比例。
- 大会 Logo、标题和个人信息继续由成片排版叠加，模型不生成文字、水印与边框。

## 外部模型参数参考

当前项目沿用现有云端图像编辑接口及后台全局模型设置，不传送 SD 或 Midjourney 专有采样参数。

SDXL 图生图建议：768×1024，DPM++ 2M Karras，Steps 30（28–36），CFG 5（4.5–6），Denoising 0.30（0.25–0.40）。换衣优先对服装区域局部重绘，强度可从 0.45–0.60 测试，面部维持较低强度。调试固定 Seed，正式随机。数值是起点，未在本项目部署 SDXL 实测。

Midjourney 建议：`--ar 3:4 --stylize 100 --chaos 8 --no text watermark neon armor headdress sunglasses`。若面部变化明显，先降至 `--stylize 50 --chaos 0`；创意用于画法和衣料，不用于五官。人物参考功能按实际版本配置。它不使用 Steps、CFG 或 Denoising。
