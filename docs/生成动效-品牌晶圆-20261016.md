# 生成动效：品牌晶圆

适用：主界面 `/`、`/vertical`，实际引用 `create-scene.js` 与 `create-scene.css`。

## 视觉

- 抠像后使用石墨黑 `#060906`、深绿 `#111810`、官网品牌绿 `#9FEF00`，Logo 使用项目原有 SpacemiT 素材（`#B0E237` 等）。
- 背景为晶圆网格、芯片轮廓、RISC-V 字样和边缘走线，人物仍在原位镜像显示。
- 抠像到位时深色背景展开、绿色方形波纹确认；人物不旋转、不缩放，保留抓拍对齐。
- AIGC 阶段持续播放晶圆掠光、纵横信号与走线节点呼吸，使用不同周期，长时间等待不停止。
- 文案仅显示真实阶段。进入生成阶段后显示本页已等待时长，45 秒后改为“仍在生成，请稍候”，不推算完成百分比。
- 结果图片解码成功后，信号动效停止，结果淡入，等待计时隐藏。
- 持续动效只改变 transform / opacity；隐藏页面暂停，减少动态效果偏好下禁用动画，销毁时清理定时器和监听器。
