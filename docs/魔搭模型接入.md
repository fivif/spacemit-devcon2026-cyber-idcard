> **开源版说明（先读这段）**
>
> 本仓库**不包含任何真实渠道地址与密钥**。代码里的默认渠道是占位值
> （`DEFAULT_BASE_URL = https://api.example.com/v1`），模型预设也只是示例清单。
>
> 接入自己的渠道有两种方式：
> 1. 操作员面板 → 渠道管理，逐个填 `base_url` / `api_key` / 模型名（密钥只存本机）；
> 2. 部署时设环境变量 `BOOTH_AIGC_BASE_URL` 作为默认地址，再在面板里填密钥。
>
> 型号名请按你自己渠道实际提供的名称写。不同渠道的同名型号版本并不一致，
> 预设里的三个名字只是模板，照抄常常对不上。
>
> 密钥保存后接口只回 `key_configured: true`，不会回显原文；也不要把密钥写进
> 任何提交进仓库的文件。

# 魔搭模型

后台进入「模型渠道」，新增或编辑渠道：

| 配置 | 内容 |
| --- | --- |
| 服务 URL | `https://api-inference.modelscope.cn/v1` |
| 模型名称 | `Qwen/Qwen-Image-2.1` |
| API Key | 自己的 ModelScope Token |
| 健康检查 URL | 留空 |
| 生成超时（秒） | 建议 `300`，包含云端排队、生成和下载 |

保存后选择图片，点击该渠道的「测试生成」。仅测试所选渠道和模型，不切换其它渠道，不创建正式照片或打印任务。

系统自动识别魔搭官方地址，以 JSON 和本地图片的 Base64 提交 `/v1/images/generations`，轮询 `/v1/tasks/{task_id}` 后下载图片；Token 只发送给魔搭接口，不发送给图片下载地址。根地址不填 `/v1` 也可自动补全。

其它 OpenAI 兼容渠道继续使用原有 `/images/edits`。魔搭提交、轮询和下载共用渠道超时，不会无限等待；失败仍参与现有渠道降级机制。

魔搭提示词上限为 4000 字符。当前已按用户要求撤回精简提示词，恢复原版完整提示词与构图规则，不自动截断或改写。超过 4000 字符时明确报错，因此原版长提示词仍无法直接使用 Qwen。魔搭异步接口及超时配置保留，后台短提示词渠道测试仍可用。

每个渠道只选择一个模型。若要优先使用魔搭，将其优先级调小（数字越小越优先）。全部风格共用最高优先级的可用渠道，失败时依次切换候补渠道；风格只配置生成说明，不再配置模型。连接检查通过只代表接口可连接，生成权限和额度以「测试生成」为准。

旧渠道的多个模型默认沿用列表第一项，保存后仅保留选定模型；原有密钥保持不变。旧的全局模型和风格模型配置不再参与生成。

2026-10-15：K3 使用已有渠道配置完成真实图片编辑，首次测试耗时 57.83 秒；更新后通过后台测试接口再次生成成功，HTTP 200，耗时 115.62 秒，输出均为 760×1280。云端生成耗时会波动。

同日正式拍摄曾因 5970 字符的美漫 Q版提示词失败，供应方返回 HTTP 400：`invalid prompt or prompt length more than 4000`。短提示词渠道测试成功不等于正式拍摄提示词通过，回归需同时覆盖正式风格编排。

精简版曾使用现场美漫 Q版风格配置及合成人像生成成功：1660 字符，48.92 秒，760×1280。用户随后反馈画面效果与人像位置不好，要求回退；该精简方案已撤回，不作为当前方案。
