## 7. 复现测量

本文件的全部数字由下列方式得出，可复现：

```python
from PIL import Image
import numpy as np
a = np.asarray(Image.open('image_2_1.png').convert('RGB')).astype(float)
h, w, _ = a.shape
print('亮度', a.mean())                      # 56.0
q = (a.reshape(-1, 3) // 16).astype(int)     # 主色分布
g = a.mean(axis=2)                           # 亮度矩阵
# 白卡区域
box = a[int(h*.46):int(h*.85), int(w*.045):int(w*.215)]
print('白卡亮度', box.mean())                 # 212.6
```
