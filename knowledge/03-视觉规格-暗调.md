## 1. 规格总表

| 维度 | 规定 |
|---|---|
| 色调 | **暗调（low-key）**：底色近黑，少量高光 |

| 高光占比 | **1%–6%**（点状，不是面） |
| 照片位置 | **左下**，`x ∈ [0.040, 0.455]`、`y ∈ [0.455, 0.975]` |
| 画幅 | 横版 **1600 × 1000**（比例 8:5），可放大到 2000×1250 / 3200×2000 |
| 内容避让 | **几何守护强制**（见 §3） |
| 底部水印带 | 下 13%（`y > 0.87`）留给信息带，低细节才正确 |

## 2. 「暗调」怎么才算成立

**暗调 ≠ 一堆深灰。** 靠三件事：

### 2.1 单一光源感
光从一个方向来（默认左上）。亮部集中在右上与右侧，暗部压死。
不要均匀铺一层深灰 —— 那是"没调好的浅色"，不是暗调。

### 2.2 发光而非填充（核心手法）
细线不能只是"亮色像素"，得**发光**。实现方式：

```python
# 单独开一个 glow 图层
self.glow = Image.new("L", (w*ss, h*ss), 0)
# 所有细线/标签/节点，同时画在普通层和 glow 层
# finish() 时按三级半径模糊 + screen 混合叠回
for radius, gain, tint in ((w*0.010, 0.55, glow_color),
                           (w*0.030, 0.34, glow2_color),
                           (w*0.075, 0.20, glow_color)):
    soft = blur(glow_layer, radius)
    base = 255 - (255 - base) * (255 - soft * tint * gain) / 255
```

三级半径分别对应**芯光 / 近晕 / 远晕**，缺一级就少了层次。

### 2.3 材质
暗调图必须有材质，否则大面积纯黑在屏幕上发灰、起色带：

```python
base += rng.normal(0, 2.6, base.shape[:2])[..., None]   # 细噪点
base += (np.arange(h) % 3 == 0)[:, None, None] * -2.2   # 每 3 行一条极轻扫描线
```

## 3. 几何守护（★ 设计约束必须由代码保证）

**"尽量避开照片区"会失效；"压到就抛异常"不会。**

```python
PHOTO_BOX = (0.040, 0.455, 0.455, 0.975)        # x0, y0, x1, y1
KEEPOUT   = (0.028, 0.443, 0.467, 0.987)        # 外扩 1.2% 留呼吸

class Guard:
    """记录所有落进照片区的内容；生成结束统一报告，有越界则 exit 1。"""
    def text(self, x, y, s, size, ...):
        # 用 PIL 的 textbbox 取真实包围盒，与 KEEPOUT 求交
    def block(self, box, label):
        # 实心/图形块的矩形与 KEEPOUT 求交
```

**它已经抓到过**：

1. **页脚压在照片上** —— 底边信息条从 `w*0.042` 起画，而照片区正是从左下角延伸的，
   **底部左侧根本没有可用空间**。改成页脚只画在照片区右侧。
2. **世代谱的第 8 行汇编越界** —— 正好落进照片区上缘。收窄到 7 行。

> 这两个都是**肉眼没看出来**的。守护的价值就在这里。

**验收**：照片区内部细节能量必须 < 1.5%（理想 0.00%）。

## 5. 文字内容规格（RISC-V）

背景上的文字**必须是真的**。编造的助记符（如把 `addi` 写成 `add.i`）
会被专业观众一眼看出来，**比没有文字更糟**。

内容来源：RISC-V 官方指令集命名（RV32/RV64 基础与扩展），实现见 `app/render/card.py` 的指令库

| 类型 | 内容 | 数量 |
|---|---|---|
| 真指令 | 助记符 + 操作数 + 语义注释，如 `addi sp, sp, -16   # rd = rs1 + imm` | **60+ 条** |
| 汇编片段 | 带标签/缩进/注释，如 `.globl kern_forward` / `vsetvli t0, a2, e8, m4` | 3 段 |
| ISA 术语 | RVA23 / RVV / CSR / Zicsr / Zba / Zve64d / LMUL / VLEN 等 | 30+ |
| 扩展字母轴 | I M A F D C V H B Zicsr，带全称 | 10 |
| **K3 实测 ISA 串** | `rv64imafdcvh_zba_zbb_zbc_zbs_zve64d_zvfh` | 1 |
| ISA 徽标 | 字母扩展 + profile 组合 | 动态 |

**自检项**：助记符字符集（只能 `[a-z0-9._]`）、操作数完整性、注释非空、片段含标签。

## 10. ⚠️ 暗调的物理限制（必须提前告知业务方）

**暗调成片在日光下看会偏灰、反光** —— 这是物理限制，不是设计问题。

三个应对：

1. **较亮的屏 + 遮光罩**（成本低，效果一般）
2. **打印走亮纸 + 高墨量**（印刷能救回来）
3. **双版本**：成片暗调（艺术照）＋ 分享图/取图页浅底（证件照）

> 第 3 条尚未实施。**开工前应向业务方确认选哪条。**

## 11. 验收指标（已修正过 4 次，见 `04` §2）

| 指标 | 判据 | 阈值 |
|---|---|---|
| 暗调成立 | 全图平均亮度 | 15 – 35 |
| 有高光 | 像素最大值 > 200 的占比 | 1% – 6% |
| **照片区干净** | 区内细节能量 = `|图 − 模糊(σ=3)| > 12` 的占比 | **< 1.5%** |
| 内容不单调 | 全图细节能量 | > 3.0% |
| 三边有内容 | 左/右/上边带细节能量 | 各 > 2.0% |
| 内容不越界 | 几何守护违规数 | **= 0（否则 exit 1）** |

**注意**：底边（水印带）**不参与**"三边有内容"判据 —— 低细节才正确。
**注意**：细节能量必须用**高频**（`|图 − 模糊|`），不能用"偏离中位色"或裸标准差。
