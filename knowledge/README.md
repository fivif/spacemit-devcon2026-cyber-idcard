## 四条纪律

这四条是从返工里换来的，违反它们正是历次做错的根因：

1. **先量，再判断。** 不凭"看起来"下结论；对参考图先测亮度、结构、区域边界。
2. **判据本身也要验证。** 指标写错比没有指标更糟——它会告诉你"全部通过"。
3. **设计约束要由代码保证。** "尽量避开照片区"会失效，"压到照片区就抛异常"不会。
4. **不猜意图。** 读不出来就问，并给出可选项。

## 与代码的关系

- 面向贡献者的上手说明在仓库根 `README.md`；系统全貌与接口契约在 `app/README.md`。
- 接口与规格冻结在 `docs/spec/`（系统规格 v2、自动流程规格 v1、仓库契约）。
- 本目录的记录反映的是**当时实测**；与代码冲突时以代码与测试为准，并请提 issue 更新本文档。
